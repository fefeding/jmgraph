border - 边框系统

通过 border 属性可以设置完整的边框，支持宽度、样式(solid/dashed/dotted/double)、颜色。 支持对象格式和 CSS 字符串格式 "2px solid #ff0000"。border 内部会自动映射为 lineWidth、strokeStyle 和 lineDash。

用法

// 对象格式
style: { fill: 'rgba(0,212,255,0.15)', border: { width: 3, style: 'solid', color: '#00d4ff' } }

// CSS 字符串格式
style: { fill: 'rgba(233,69,96,0.15)', border: '3px dashed #e94560' }

// 虚线边框
style: { fill: 'rgba(0,255,136,0.15)', border: { width: 3, style: 'dotted', color: '#00ff88' } }

// 双线边框
style: { fill: 'rgba(192,132,252,0.15)', border: { width: 3, style: 'double', color: '#c084fc' } }

// 使用 jmBorder 类
import { jmBorder } from 'jmgraph';
const b = new jmBorder({ width: 4, style: 'dashed', color: '#ffd93d' });
style: { border: b }
